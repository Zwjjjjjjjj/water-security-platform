## 三、素材规格要求

### 3.1 通用规则

| 项目 | 要求 |
|---|---|
| 格式 | PNG（带透明通道的必须用 PNG，不能用 JPG） |
| 颜色空间 | sRGB |
| 命名 | **严格按上表文件名**，否则会被判定为「素材缺失」并自动回退到矢量绘制 |
| 朝向 | **正上方为北**（与场景 ENU 坐标系一致，y 向下为南） |

### 3.2 厂区航拍底图 `campus_aerial.png` ★最重要

这是决定 V2 效果的核心素材。

| 项目 | 要求 |
|---|---|
| 视角 | **正俯视（正射/orthophoto）**，不要透视倾斜 |
| 建议分辨率 | **≥ 3000 × 1500 px**（越大越好，放大后不糊） |
| 内容 | 草地/林地、道路、停车场、建筑物屋顶、岸线、礁石都要在 |
| 构图 | 建议：厂区占画面上方 ~1/3，岸线横贯中上部，下方留出大片海域 |
| 长宽比 | 建议 **2:1**（与设计坐标系 1000×500 一致） |

**配准信息**（可选但强烈建议提供）：
在 `manifest.json` 的 `campus_aerial` 条目里填：

```json
"world_bounds_enu": [-2200, 3000, 1200, 4900]
```

这四个数是 **ENU 范围 `[东向最小, 北向最小, 东向最大, 北向最大]`（米）**，
表示这张图对应现实中的哪一块区域。填了就能和实测航迹**精确对齐**；
不填则按设计坐标估算，视觉可用但航迹会有偏移。

> 当前占位图已经预填了 `-2200, 3000, 1200, 4900`。
> 如果你的新图对应的是同一片区域，保持不变即可。

### 3.3 海面贴图 `sea_surface.png`

| 项目 | 要求 |
|---|---|
| 建议分辨率 | 1024 × 1024 px 或 2048 × 2048 px |
| 关键 | **四边无缝、可平铺（seamless tileable）** |
| 风格 | 参考图的海面是「近岸浅青绿 → 远海深蓝」，颜色层次要柔和自然 |
| 禁止 | 不要有明显的暗角、接缝、明显重复的浪花图案 |

海面会以 **每 200 设计单位平铺一次** 的密度铺满视口，所以**必须无缝**。

### 3.4 防波堤 / 护岸 `breakwater_tex.png`

| 项目 | 要求 |
|---|---|
| 建议尺寸 | 512 × 128 px 的**横向条带**（沿堤坝走向平铺） |
| 关键 | **左右无缝**（水平方向可平铺） |
| 内容 | 块石堆砌、混凝土护面、堤顶步道 |
| 透明 | 堤身以外的区域透明 |

### 3.5 船型贴图

| 项目 | 要求 |
|---|---|
| 视角 | **正俯视**（俯视看到船甲板、船艏朝上） |
| 建议分辨率 | 1024 × 1536 px |
| 透明 | 船体以外必须透明 |
| 尺寸标注 | `length_m` / `beam_m` 是**真实船长/船宽（米）**，用于换算水线尺寸 |

**特别注意**：现有 V1 素材的船是 **45° 斜俯视**的（能看到船舷侧面），
而参考图里的船是**正俯视**（只看到甲板）。所以新素材需要重新提供，
**现有的占位船图不要直接用**。

## 四、缺失素材会自动降级

每个素材在加载时都会做一次 **HEAD 探测**（`scene-assets.v2.ts` 的 `probeAsset()`）：

- 探测通过 → 用贴图渲染
- 探测失败（404）→ **自动跳过该层**，下面一层顶上

降级链：

| 层 | 有素材时 | 缺素材时 |
|---|---|---|
| 厂区底图 | 写实航拍图 | 矢量色块陆域 |
| 海面 | 平铺写实贴图 | 三段式渐变 + 近岸浅水带 |
| 防波堤/护岸 | 石砌纹理带 | 矢量描边条带 |
| 灯桩/浮标 | PNG 图标 | 简笔符号（圆点） |
| 船只 | PNG 贴图 | 不显示 |

控制台会打印提示：

```
[scenes-v2] 以下素材尚未提供，已回退到矢量绘制： nav_beacon, radar_station
```

**所以你可以分批给素材**，每给一批刷新页面就能看到效果，不用等齐了再开始。

## 五、素材到位后的调优项

新素材进来后，以下几项通常还需要微调（都在配置里，不用改渲染代码）：

| 文件 | 调什么 |
|---|---|
| `scenes.config.v2.ts` → `NPP_PLACEMENTS` | 建筑/构筑物锚点与尺寸（写实底图自带建筑时保持 `enabled: false`） |
| `scenes.config.v2.ts` → `BACKGROUND_SHIPS` | 背景船位置与航向 |
| `scenes.config.v2.ts` → `BG_ANCHOR` / `BG_UNIT` | 底图锚点与比例（决定航迹与底图的对齐） |
| `structures.v2.ts` → `STRUCTURES` | 防波堤/护岸的走向折线与宽度 |
| `manifest.json` → `world_bounds_enu` | 底图的精确配准范围 |
